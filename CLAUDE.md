## Project state

This is a learning project: a RAG (Retrieval-Augmented Generation) pipeline built incrementally, one stage at a time, to understand how RAG works end to end rather than to ship a polished tool. `sentence-transformers` + `faiss-cpu` handle retrieval; generation uses a local **Ollama** server running **phi-3** (not `transformers`/`torch` directly — those are in `requirements.txt` but currently unused; Ollama is the actual generation backend).

## Environment setup

A venv already exists at `.venv` (Python 3.10). To work in it:

```

pip install -r requirements.txt
```

Ollama must be running locally with the `phi3` model pulled (`ollama pull phi3`) for the generation step to work.

There are no lint or test commands yet — this is a single learning script, run directly:

## Running the RAG system

```
.venv\Scripts\python.exe rag.py
```

Loads the knowledge base, builds embeddings/index on startup, then drops into an interactive Q&A loop. Type questions at the prompt, get answers generated by local Ollama phi-3, or empty line to quit.

## Pipeline architecture (`rag.py`)

Single script, built up as a linear sequence of stages:

1. `load_documents` / `chunk_text` / `chunk_documents` — read each `.txt` file and split into ~150-word chunks (word-count slicing, no overlap), producing a flat list of `{source, chunk_id, text}` records.
2. `embed_chunks` — encodes chunk texts with `sentence-transformers` (`all-MiniLM-L6-v2`, 384-dim) into a numpy array.
3. `build_faiss_index` — loads those embeddings into a `faiss.IndexFlatL2` (exact brute-force search).
4. `search` — embeds a question with the same model, queries the FAISS index for the top-k nearest chunks.
5. `build_prompt` — assembles instructions + retrieved chunks (labeled by source) + the question into one prompt, instructing the model to answer only from context or say "I don't know".
6. `ask_ollama` / `answer_question` — POSTs the prompt to a local Ollama server (`http://localhost:11434/api/generate`, model `phi3`) and returns the generated text.

Pipeline is end-to-end and working. Tested: in-domain questions (RAG-related) get grounded answers; out-of-domain questions (FAISS internals, which aren't in the knowledge base) correctly refuse with "I don't know" instead of hallucinating.
